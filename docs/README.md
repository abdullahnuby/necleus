# Nucleus Pulse

مشروع تجريبي لاستكشاف خلايا ديناميكية وإشارات نبضية والتعلّم، مع فصل صارم بين سلامة التنفيذ والدليل على القدرة على التعلم.

## أحدث حالة موثقة

- **v0.42:** تشغيل رسمي لمقارنة قارئ STDP بممرّة واحدة مع baseline خطي معياري.
- **v0.42.1:** تصحيح تفسير النتائج وخطة المرحلة التالية.
- **v0.42.2:** مواصفة v0.43 بعد إصلاح بوابات الامتناع وفضاء الفرضيات وخط الأساس التعلمي والعائلات والتوازن والتعلم من الأخطاء.
- **v0.43-stage1:** تنفيذ أولي لمولد DSL محدود، وعدّ فرضيات دقيق على المجال، وتصنيف قابلية التحديد، وتقسيم عائلي ومنع تسرب. اجتازت 9 اختبارات جديدة. هذه مرحلة أدوات/بيانات فقط؛ لم يُنفذ meta-learner أو حلقات feedback/retention، وليست benchmark رسميًا.

## النزاهة التجريبية

نتائج v0.42 الرسمية وسجلاتها محفوظة كما هي. ضوابط 12 بذرة ونتيجة GBM التي أبلغ عنها المستخدم موصوفة كبيانات خارجية لم يُعَد تشغيلها داخل هذه الحزمة. تنفيذ v0.43-stage1 يختبر ميكانيكا المولد والتصنيف ومنع التسرب فقط؛ لا توجد نتائج أداء لنموذج تعلم. لا يُفتح الاختبار النهائي قبل اكتمال بقية بوابة التسجيل المسبق.
