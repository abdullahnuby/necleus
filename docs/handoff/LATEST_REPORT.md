- **ما تدعمه الأدلة:** إصلاح اختيار العتبة كشف أن العيب التاريخي لم يكن السبب الوحيد؛ لا توجد عتبة ممكنة لـDeepSets حتى بعد 20 حقبة أو 20,000 حلقة.
