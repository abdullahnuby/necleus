# ملاحظة تدقيق التنفيذ — v0.35

في أول تشغيل تجريبي كامل، اكتُشف قبل اعتماد النتائج النهائية أن تنفيذ EMA كان يحدّث الأثر بمعدل النشاط الابتدائي صفر قبل حساب كسب أول tick، بينما نص البروتوكول المجمد على أن الكسب الابتدائي يساوي 1.0 قبل مشاهدة نبضات المثال. لم تُستخدم نتائج التشغيل الأول في التقرير النهائي. عُدّل ترتيب التنفيذ إلى: استخدام EMA الحالي للكسب، ثم تحديث EMA بعد نبضات tick الحالي ليُستخدم عند tick التالي. أُعيد تجميد بصمات السكريبت والاختبار والبروتوكول، وأُعيد تشغيل جميع البذور الرسمية من الصفر؛ لم تُخلط سجلات التشغيلين.
