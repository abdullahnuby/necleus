# قائمة التسجيل المسبق — v0.43

لا يبدأ الاختبار الرسمي حتى يتم التحقق من جميع البنود وتسجيل hashes. أي بند غير مكتمل يمنع وصف التشغيل بأنه benchmark نهائي.

## المهمة والgrammar
- [ ] grammar الأساسية والأنواع وحدود حجم البرنامج وعمقه مجمدة.
- [ ] تعريف العائلة والتطبيع وقاعدة AST hash مجمدة.
- [ ] المسار A مُعلن باعتباره استنتاج برنامج من فضاء مغلق لا دليلًا منفردًا على تعلم مهارة عامة.
- [ ] مسار العملية الجديدة/meta-grammar والافتراضات اللازمة للتعلم من أمثلتها موثقة.

## التقسيم والعينات
- [ ] ≥100 عائلة train و≥10,000 حلقة مهمة للـmeta-learning.
- [ ] ≥20 عائلة development منفصلة.
- [ ] ≥30 عائلة test محجوزة، والهدف ≥50.
- [ ] ≥20 مهمة لكل عائلة test أو توثيق انحراف مسبق عن هذا الرقم.
- [ ] 8 أمثلة دعم لكل مهمة A.
- [ ] 100 استعلام متوازن 50/50 لكل مهمة، مع فحوص التمييز وعدم تكرار المدخلات.
- [ ] تعداد البرامج المتسقة وفئات التكافؤ الدلالي ومقياس اختلاف التنبؤات تم قبل الاختبار ومخرجاته مخفية عن النظام.

## حالات الامتناع
- [ ] تعريف وتصنيف منفصل للحالات القابلة للتحديد، والملتبسة، والخارجية، والمتناقضة.
- [ ] identifiable: coverage ≥90% وrisk ≤5%.
- [ ] ambiguous/OOD/contradictory: abstention ≥90% وfalse acceptance ≤10%.
- [ ] عتبة الامتناع معايرة على development فقط.

## Baselines
- [ ] constant، retrieval، linear/tree من الدعم، program induction، وmeta-learning neural baseline.
- [ ] شبكة DeepSets محددة: φ من طبقتين MLP (128/ReLU)، mean-pooling للدعم، وρ من طبقتين MLP (128/ReLU)، وتدريب عبر ≥10,000 مهمة من ≥100 عائلة.
- [ ] المقارنة الرئيسية +10 نقاط محددة مقابل شبكة meta-learning؛ program induction منشور كخط أساس تركيبي مستقل ولا يُخفى إذا تفوق.
- [ ] كل الطرق لا ترى البرنامج الصحيح ولا تسميات final evaluation.
- [ ] oracle محصور في تدقيق المولد والمفسر.
- [ ] أي GBM عند 6000 مثال يعرض كميزانية منفصلة ولا يقارن مباشرة باختبار 8-shot.

## التصحيح وعدم النسيان
- [ ] ثلاث جولات feedback، 50 استعلام تفاعل جديدة لكل جولة.
- [ ] تظهر التسمية الصحيحة للأخطاء فقط؛ لا تظهر تسميات الإجابات الصحيحة.
- [ ] 100 استعلام final ثابتة لا تدخل feedback ولا تتكشف للنظام.
- [ ] تسلسل ≥20 مهارة، واختبار الاحتفاظ بعد كل مهارة جديدة.
- [ ] مقاييس Round 0→3 وaverage/worst forgetting مثبتة.
